# control-system-simulator
一個基於網頁的自動控制模擬器，提供 PID、LQR、滑膜控制 (SMC) 及模糊控制的即時動態響應圖表與物理動畫。支援自訂 PID 函數編寫與 Z-N 調參。A web-based automatic control simulator featuring real-time dynamic charts and physics animations for PID, LQR, Sliding Mode Control (SMC), and Fuzzy Control. Supports custom PID script execution and Z-N tuning.
